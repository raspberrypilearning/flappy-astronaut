## What you will need

### Hardware
If you are not using an emulator you will need the following hardware:
+ Raspberry Pi
+ Sense HAT

If you don't have a Sense HAT, you can use the Sense HAT emulator in the [Code Editor](https://editor.raspberrypi.org/en/projects/blank-python-starter){:target="_blank"} for most of this project. The emulator doesn't have a joystick, so you will need a real Sense HAT for the steps where your astronaut is controlled with the joystick.

### Software
You will need the [latest version of Raspbian](https://www.raspberrypi.org/downloads/), which already includes the following software packages:

- Python 3
- Sense HAT for Python 3

If for any reason you need to install a package manually, follow these instructions:

[[[rpi-install-software]]]

Type this command into a terminal window to install the Sense HAT package:

```bash
sudo apt-get install sense-hat
```
